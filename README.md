# Biotech AI Teacher

An educational web application that helps biotechnology students learn topics such as DNA, RNA, PCR, CRISPR, ELISA, and Bioinformatics.

## Features
- Topic explanations
- Applications of biotechnology concepts
- Viva questions and answers
- Easy-to-use web interface

## Technologies Used
- Python
- Flask
- HTML
- CSS

## Project Structure

## How to Run

1. Install requirements:
   pip install -r requirements.txt

2. Run the application:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000
